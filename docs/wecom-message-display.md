# 企微消息展示

2026-10-14 核对企微智能机器人官方文档：[长连接](https://developer.work.weixin.qq.com/document/path/101463)、[被动回复](https://developer.work.weixin.qq.com/document/path/101031)和[主动回复](https://developer.work.weixin.qq.com/document/path/101138)均标注最后更新为 2026/10/10。页面修改日期不能用于判断每项能力的新增时间；明确的新增能力见[官方更新日志](https://developer.work.weixin.qq.com/document/path/93221)。

智能机器人的流式回复和 Markdown 消息支持常见 Markdown，单条内容上限为 20,480 个 UTF-8 字节。中文与 emoji 须按实际字节计算。群机器人 Webhook 的 `markdown_v2` 属于另一接口，不能直接套用于智能机器人长连接。

业务回复先显示实际结论，关键状态和数字加粗；参数、运行信息与报告分段，路径使用行内代码，真实可访问的报告网址使用链接。多主机结果逐项展示，避免在手机上使用宽表格。摘要不再输出 YAML/JSON，也不放进整段代码框。

长回复按段显示，后续段保留为独立消息；进度更新保持单条可更新消息，最终结果包含完整内容。等待时保留一次静态处理提示，使用企微原生流式指示；只在可见正文变化时刷新，不定时更新运行秒数或动画点。流式窗口到期前仍会收尾并切换后台回传，静默回退缺省跟随窗口到期阈值。代码跨段时各段保留有效围栏和语言标记。分段遵守 UTF-8 字节上限，并为群聊提醒预留空间。

过程消息采用“运行状态 + 具体摘要”：例如 `**运行状态：分析中**`，空行后显示“正在核对配置和日志，确认摘要没有更新的原因”。英文固定阶段标签合并为中文状态（分析中、执行中、处理中、修改中、检索中、整理中、重试中），摘要不再添加“分析：”前缀。

状态和摘要分别保存；工具事件只更新状态，没有新摘要时保留上一条具体描述。每 5 秒检查一次，只有可见内容变化才更新。摘要使用 Codex/Claude 的阶段文字或明确的 summary，命令、参数、原始输出和内部推理不会作为摘要显示。最终答案独立保存，不受摘要截断影响。

协议测试按官方的覆盖语义模拟客户端消息显示，并验证长文本、中文、emoji、代码缩进、代码围栏、群聊提醒，以及中途发送失败后的剩余内容回传。尚未通过真实企微客户端验证排版。
